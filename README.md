# Python Mini Projects

Small physics, math and data projects in Python.

| Project | Description |
| --- | --- |
| [NBA Game Predictor](nba-game-predictor) | XGBoost model that predicts NBA game winners from recent team form and season averages |
| [Projectile Motion](projectile-motion) | Trajectory of a projectile with or without quadratic air drag |
| [Ice Melt Time](ice-melt-time) | How long a sphere of ice takes to melt in a room, from convection and radiation |
| [Palindrome Depth](palindrome-depth) | Groups integers by how many reverse-and-add steps they need to become palindromes |

## Setup

```bash
git clone https://github.com/abirpogo421-spec/python-mini-projects.git
cd python-mini-projects
pip install -r requirements.txt
```

Each folder has its own README with instructions for running it.
